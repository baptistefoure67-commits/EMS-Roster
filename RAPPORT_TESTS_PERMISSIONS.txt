Date : 21/10/2026

Résultat global : 28 tests réussis, 0 échec.

Ajout testé :
- Une demande ACCEPTÉE / REFUSÉE / ANNULÉE peut être supprimée de l'historique des demandes par une personne disposant de « Gérer les permissions ».
- Une demande encore EN ATTENTE ne peut pas être supprimée : elle doit d'abord être traitée ou annulée.
- La suppression d'une demande acceptée ne retire PAS la permission individuelle déjà appliquée à la personne.
- Un utilisateur sans « Gérer les permissions » ne peut pas supprimer une demande.
- Le bouton 🗑️ Supprimer n'est proposé que pour les demandes déjà traitées.
- La suppression passe par la fonction Netlify permission-requests.js, pas par une suppression Firebase directe depuis le navigateur.
- Une trace d'audit « demande_permission_supprimee » est ajoutée aux logs.

Contrôles techniques :
- JavaScript frontend : syntaxe valide.
- Fonctions Netlify : syntaxe valide.
- Aucun ID HTML statique dupliqué.
- Règles Firebase : JSON valide.
- Compatibilité avec les animations Synchroniser/Sauvegarder conservée.
